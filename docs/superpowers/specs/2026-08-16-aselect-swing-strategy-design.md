- 日期:2026-08-16
- 状态:已通过 brainstorming 设计 + grill-me 校验,待用户 review
- 作者:Claude(brainstorming/grilling 协作)
- 关联宪法:`CLAUDE.md`(北极星、七条铁律、因子开发规范)

---

## 1. 背景与用户画像

用户是**偏保守的右侧波段交易者**:持仓 1–2 周、跟热点板块(近期医药)、靠情报与系统信号决策、会果断止盈。经画像分析,其**两大真实风险**是:

1. **追高**:在标的日内已大涨、偏离均线过远时进场(泰格 +4% 追进、顺钠反复想接飞刀)→ 买在高位,**压低期望收益**。
2. **过早止盈(卖飞)**:涨停即全清(大唐涨停清仓 +1380)→ 锁小胜、砍掉右侧趋势,**砍掉盈亏比**。

次要风险:决策犹豫/延迟、板块集中度(医药泰格+爱尔同跌)。

**关键认知(设计立场的根)**:这两大风险**都是「期望 / 盈亏比」问题,不是胜率问题**。用户初始诉求「提高胜率」与项目北极星冲突,且**追求胜率会诱导更早止盈**,反而放大第二个风险。经对齐,本方案目标改写为:

> **在用户的中波段右侧风格下,最大化「风险调整后 · 扣除全部成本 · 样本外」的期望收益**,并用两个专门确定性机制正面打击两大风险:**反追高入场闸门** 与 **反卖飞移动止损离场**。

胜率/准确率仅作只读参考,**不作为优化或验收目标**(遵铁律 #4)。

---

## 2. 目标与非目标

### 2.1 目标
- 在 `stock-recommendation`(aselect)精简确定性核心上,新增完整闭环:**多因子选股 → 反追高入场闸门 → 反卖飞离场纪律 → 飞书推送 → walk-forward 回测验证**。
- 从 `daily_stock_analysis`(DSA)**只借确定性能力并干净重写**:数据源增强、热点因子、飞书通知、AI 舆情情绪(正交因子)。
- 用回测**消融实验**把用户两大风险「量化成钱」:入场闸门带来的期望增量、移动止损相对「涨停即清」的盈亏比提升。

### 2.2 非目标(明确排除)
- **不引入任何 DSA 依赖**,不搬 DSA 的 LLM 决策架构(架构性违反铁律 #1)。
- **不在 engine 数值核心内调用任何 LLM**(`test_no_llm_in_core` 继续守护)。
- **不做胜率/准确率优化**。
- 不做多市场(仅 A 股沪深京);不做防御底仓的资产配置(视为组合层面人工决策,系统只管选股/交易信号)。
- 不做波动率目标仓位(MVP 用等权;留待后续)。

## 3. 架构与模块边界

依赖方向不变:`datasource → data → engine`;`ai` 只接输入端,`notify` 是输出外壳,**二者都不被 engine 引用**。

```
src/aselect/
  datasource/
    akshare_source.py      ← 新增:个股资金流、龙虎榜标记、板块资金流、涨跌停状态、换手率
  data/
    pipeline.py            ← 新增:hotspot 特征构建、sentiment 结构化落地
  ai/
    sentiment_*.py         ← AI 只在文本输入端产出情绪分(M4;缺 Key → NullAnalyzer)
  engine/                  ← AI 禁区
    factors.py             ← 新增:hotspot、sentiment 两个正交因子
    strategy_rules.py      ← 【新核心】反追高入场闸门 + 反卖飞离场纪律(纯确定性)
    strategy_backtest.py   ← 扩展:周级候选 + 每日逐仓离场 + 摩擦/T+1/涨跌停
  notify/                  ← 【新外壳】Notifier 接口 / FeishuWebhookNotifier / NullNotifier(~150 行)
```

守护:`test_no_llm_in_core` 静态测试断言 `engine/` 不 import `ai/`;新增 `strategy_rules.py`、`strategy_backtest.py`、`factors.py` 均纳入该守护范围。

## 4. 数据层(datasource / data)

### 4.1 新增抓取字段(akshare 适配器)
按**交易日 / 披露日 point-in-time** 对齐,落地为截面特征表列:

| 字段 | 用途 | PIT 历史 |
|---|---|---|
| 个股资金净流入 | 热点因子、实盘信号 | 历史深度有限 → 见 §4.2 |
| 龙虎榜标记 | 事件标记、实盘信号 | 稀疏事件 |
| 所属板块 / 板块资金净流入 | 热点因子 | 当日盘后可得,T+1 用无前视 |
| 涨跌停状态 | 入场闸门、回测「涨跌停无法成交」 | 日频有历史 |
| 换手率 | 入场闸门量能确认、因子 | 日频有历史 |

### 4.2 防前视铁规则(遵铁律 #2)
> **任何缺乏 point-in-time 历史的字段,一律剔出回测因子,只用于实盘实时信号。**

- 日频资金流 / 换手 / 涨跌停:有历史 → 可入回测因子(T 日盘后数据、T+1 使用,无前视)。
- 龙虎榜、深度不足的个股资金流:仅作实盘信号,**不进回测因子**。
- 原则:**宁可少一个因子,不可引入前视**。

## 5. 因子层(engine/factors)

所有因子入库前:**去极值(Winsorize)→ 标准化(Z-score)→ 中性化 → 再 Z-score → 方向统一**;新因子先**单独 walk-forward IC 验证**(IC 稳定 0.03~0.05 才纳入加权)。

### 5.1 热点因子(正交,契合热点跟踪)
- 构成:板块相对强度(板块 vs 指数动量)+ 板块资金净流入 + 板块涨停广度 + 个股在板块内相对位置。
- **中性化特例**:热点因子本质是「板块归属 + 板块强度」,**做行业中性会自我抵消**。故**跳过行业中性,只做去极值 + Z-score + 市值中性**,再对已有因子做残差正交化。
- 单独 IC 先验后再决定权重。

### 5.2 AI 舆情情绪因子(正交,M4,默认关)
- 文本源:**akshare 个股新闻 / 公告**(免费,不引 SerpApi、不依赖 DSA)。
- AI 只在文本端产出情绪分 → 结构化入库 → 对其它因子正交化后作为因子。**绝不直接预测涨跌**(遵因子规范)。
- 热插拔:`ai.enabled=false` 或缺 Key → NullAnalyzer,**MV(M1–M3)不依赖它,核心完整可跑**。

### 5.3 复用
沿用现有 value / growth / quality / momentum / lowvol 因子及其处理管线。

## 6. 策略纪律层(★ 本方案核心)`engine/strategy_rules.py`

纯确定性,相同输入恒得相同输出。位于 engine,**AI 禁区**。

### 6.1 反追高入场闸门
选股打分选出候选后,**逐条 gate,全过才允许入场**(阈值为固定常识初值,训练段仅做粗敏感性检验、不精调,遵铁律 #3):

| 闸门 | 默认规则 | 治的病 |
|---|---|---|
| 不追日内大涨 | 当日涨幅 > **+3%** 或接近涨停 → 拒 | 泰格 +4% 追进 |
| 不偏离均线过远 | (close/MA20 − 1) 过热 → 拒 | 买在高位 |
| 右侧确认(不接飞刀) | 需 close > MA5 且非自由落体 → 拒 | 顺钠接飞刀 |
| RSI 不过热 | RSI(14) > **70** → 拒 | 追顶 |
| 量能确认 | 换手 / 资金流参与但非天量出货 | 假突破 |

未通过闸门的候选**不下单**,等下一次非过热的右侧入场点。

### 6.2 反卖飞离场纪律
用结构化移动止损替代「涨停即清」,让利润奔跑:

| 规则 | 默认参数 | 治的病 |
|---|---|---|
| ATR 吊灯移动止损(主) | ATR(14),离场线 = 入场后最高收盘 − **3×ATR** | 大唐涨停就全清 |
| 分批止盈 | 盈利达 **2R**(R = 初始风险)减仓 **1/2**,剩余跟踪止损 | 卖飞右侧趋势 |
| 趋势离场(辅确认) | 收盘**跌破 MA10** 触发离场 | 单日涨停即锁小胜 |
| 硬止损(兜底) | 入场价 − **2×ATR** | 追高下行、控回撤 |
| 最大持仓 | **20 交易日**(≈4 周),超时且趋势转弱即了结 | 中波段纪律 |

## 7. 回测与验证(engine/strategy_backtest)

### 7.1 回测粒度(匹配 1–2 周持仓)
现有回测是月级,无法表达入场闸门/移动止损。改为:
- **周级刷新候选**:每周对全池打分,候选通过入场闸门后 **T+1 开盘**下单;
- **每日逐仓离场检查**:止损 / 趋势破位每日盘后计算,**T+1 执行**。
- 复用现有 panel 回测骨架 + 摩擦计算,新增日级逐仓离场逻辑。

### 7.2 交易摩擦与约束(遵铁律 #5)
计入佣金、印花税(卖出单边)、过户费、滑点;模拟 **T+1**、**涨跌停无法成交**;执行价 = T+1 开盘(滑点兜底极端情形)。**Long-only 现金账户**。

### 7.3 防泄漏与验证方法(遵铁律 #2/#3)
- 股票池**含历史退市 / ST**(aselect 已内建 status L/ST/D + delist_date,`include_delisted=True`;策略层显式启用)。
- **walk-forward** 滚动前推拟合 IC 权重;**样本外 = 训练 70% / OOS 30%,只测一次**,禁止在 OOS 上反复调参。

### 7.4 评估指标(遵铁律 #4)
只报 **IC / 夏普 / 期望 / 最大回撤 / 盈亏比**;基准 **沪深300(000300)+ 中证全指(000985)**;胜率仅参考不验收。

### 7.5 消融实验(把两大风险量化成钱)—— 核心验收依据
- **①入场闸门**:有闸门 vs 无闸门,样本外**期望增量 > 0**。
- **②移动止损**:ATR 吊灯 vs「涨停即清 / 固定止盈」基线,**盈亏比提升**。
- 单因子:IC 稳定 0.03~0.05 才纳入加权。
- 策略级:样本外**夏普 > 基准**且最大回撤可接受。

## 8. 通知层(notify)

- `aselect/notify/`:极简飞书 webhook 适配器 + `NullNotifier` 回退,配置驱动(webhook / 开关走 `config.yaml` 与环境变量),**纯格式化无 LLM**,约 150 行(对照 DSA 的 3119 行 `NotificationService` 上帝类)。
- 推送三类:**每日候选**(打分 + 各闸门通过状态)、**持仓离场提醒**(移动止损 / 趋势破位触发)、**风险预警**(行业集中度、追高提示)。
- `enabled=false` 或缺 webhook → NullNotifier,核心照跑。

---

## 9. 仓位与集中度

- **等权 top-N,默认 N=10,单行业 ≤ 2 只**(直接压制「医药泰格+爱尔同跌」的集中度风险)。
- 仓位大小 MVP 用等权,暂不做波动率目标。
- **防御底仓(工行)不纳入系统**,视为组合层面人工资产配置决策。

---

## 10. 配置驱动(遵铁律 #6)

数据源 / 因子权重 / 闸门阈值 / 离场参数 / 仓位与集中度 / AI 开关 / 飞书 webhook 全走 `config.yaml`,**改配置不改业务代码**;`enabled=false` / 缺 Key / 缺 webhook 全部优雅回退,**确定性核心完整可跑**。

## 12. 验收标准(汇总)

1. 单因子:IC 稳定 0.03~0.05 才纳入加权。
2. 消融①:入场闸门带来样本外期望增量 > 0。
3. 消融②:移动止损相对「涨停即清」基线盈亏比提升。
4. 策略级:样本外夏普 > 基准,最大回撤可接受。
5. OOS 只测一次;股票池含退市/ST;全程计入摩擦 + T+1 + 涨跌停。
6. `ai.enabled=false` / 缺飞书 webhook 时,确定性核心完整可跑。
7. `engine/` 无任何 LLM 调用(`test_no_llm_in_core` 通过)。
8. **全程不以胜率/准确率作为优化或验收目标。**

## 13. 关键风险与缓解

| 风险 | 缓解 |
|---|---|
| 阈值过拟合(数据挖矿) | 固定常识初值,训练段仅粗检验,OOS 只测一次 |
| 数据前视(资金流/龙虎榜无 PIT) | §4.2 铁规则:缺 PIT 历史者剔出回测因子,仅实盘 |
| 热点因子被行业中性抹平 | §5.1 特例:跳过行业中性,只市值中性 + 正交化 |
| DSA 臃肿/LLM 决策污染核心 | 只干净重写确定性能力,零 DSA 依赖,engine AI 禁区守护 |
| 回测引擎改造复杂度 | 复用 panel 骨架,增量加日级逐仓离场,不推翻重写 |
