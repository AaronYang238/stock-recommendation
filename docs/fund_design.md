# 基金推荐子系统 v1 设计文档（docs/fund_design.md）

> 2026-09 预注册设计。原则与股票侧一致：**确定性核心、无前视（PIT）、扣全部费用后
> 风险调整收益为北极星**。本文件记录设计决策、预注册项与已知局限。

## 1. 范围（v1）

- **标的**：场外开放式基金（股混型为主，来自 `fund_open_fund_rank_em` 的
  股票型/混合型名单）+ 场内 ETF（`fund_etf_fund_daily_em`）。
  货币/债券/FOF/LOF 非优先。
- **数量级**：全市场股混基金 ~5000 只 → 初筛（规模>2亿、成立>1年、近1年夏普>0）
  → 300~800 只拉全量净值历史落库。

## 2. 数据层

| 数据 | 来源接口 | 落库表 |
|---|---|---|
| 基金名单+近1年业绩 | `fund_open_fund_rank_em`（股票型/混合型） | `fund_info` |
| 单基金净值历史 | `fund_open_fund_info_em(symbol, indicator=单位净值走势)` | `fund_nav` |
| ETF 名单 | `fund_etf_fund_daily_em` | `fund_info(kind=etf, 代码加 etf: 前缀)` |
| 基金规模/成立日期 | `fund_individual_basic_info_xq`（按需、仅业绩粗筛后） | `fund_info` 补列（只回写增量列，防整行覆盖） |
| 重仓股（TopN 相关性提示） | `fund_portfolio_hold_em`（季度、不进回测） | 不落库，实时拉 |
| 基准指数 | `stock_zh_index_daily(sh000300)`（东财指数接口经代理不稳，用新浪源） | `index_daily` |

- 初筛流水线：名单接口业绩粗筛（近1年收益≥0 且非 NaN，~5300 只）
  → 逐只查规模/成立日期（xq 接口对大量新基金无数据，KeyError('data') 按
  "缺规模"剔除）→ 规模≥2亿 + 成立≥1年 → 候选。
- `upsert` 是整行 OR-REPLACE：**增量列回写必须"读全行→改列→写回"**，
  不能只写部分列（会把同 PK 行的其余列抹成 NULL——已踩坑并修复）。

- `fund_nav(fund_code, nav_date, nav, accum_nav, PK(fund_code,nav_date))`，
  走 storage 层新方法 `upsert_fund_nav / get_fund_nav / get_fund_nav_wide`。
- **幂等**：重复 sync 以 PK OR-REPLACE 覆盖，无重复行。
- akshare 接口偶发超时：重试（指数退避）+ 限速 sleep(0.5~1s)，批量拉取带进度日志。

## 3. 信号（v1：净值动量 + 风险调整，无预测）

月频（每自然月最后一个交易日收盘后计算）。候选池为初筛后基金，**只用净值序列**，
不碰持仓/经理因子（避免前视；持仓数据若未来启用须按报告期+15日披露延迟对齐）。

因子（全部由截至 T 日的净值历史计算，天然无前视）：

1. `mom3`：近 3 月日收益年化夏普（风险调整动量）
2. `mom6`：近 6 月年化夏普
3. `dd_pen`：近 6 月最大回撤（分位数惩罚，回撤越深分越低）
4. `size_fee`：规模/费率惩罚（规模<2亿扣分、申赎费率越高扣分；缺失按中性别加分）

- 合成：各因子截面 Z-score 后按 **ICIR 收缩定权**（复用 `factor_weights` 模式：
  训练段滚动验证窗口内各因子对下月收益的秩 IC 的 ICIR，取正部，单因子上限 0.4，
  向正 IC 因子等权收缩 0.5）。ICIR 全非正 → 等权兜底。
- **权重只用 T 日之前的数据估计**（滚动 walk-forward），无未来函数。
- 候选因子（波动率倒数、换手稳定性）不进默认合成；CLI 提供
  `fund-screen --factor-report` 式单因子验证入口（复用 factor-ic 模式）。

## 4. 回测（宪法级）

- **调仓**：每月最后一个交易日出信号 → **下一交易日净值确认**（场外基金 T+1
  申赎）。同一基金持有期跨月的，赎回费按实际持有天数计阶梯。
- **成本模型（config 可调）**：
  - 申购费：打折后 0.15%（申购金额×费率/(1+费率) 外扣法）
  - 赎回费阶梯：<7 天 **1.5%**（惩罚性费率，月频策略不触发但必须建模）、
    <30 天 0.75%、<365 天 0.5%、≥365 天 0
  - ETF（场内）：佣金万 2.5 + 滑点 5bps
- **记账**：组合账本逐日按持有基金净值估值；月末按目标权重再平衡
  （TopN 等权）；新调入买入、调出卖出、留任者只做漂移再平衡。
- **基准**：沪深300（000300，新浪源日线）。
- **报告指标**：年化收益、年化夏普、最大回撤、Calmar、分年收益表、月度收益序列。
  **月度胜率仅作展示，禁作优化/验收目标**。
- **OOS 纪律**：`fund-backtest --oos 0.7` 复用 `runner._register_oos` 登记样本外
  使用次数，报告 Deflated Sharpe（复用 `engine/stats.py`）。

## 5. 预注册设计决策（不再中途调整）

- TopN=10、等权；调仓日=每月最后一个交易日；信号 T 日 → 成交 T+1。
- 因子窗口：动量 63/126 交易日，回撤窗口 126 交易日。
- 初筛阈值：规模 ≥2 亿、成立 ≥1 年、近1年收益>0（近似近1年夏普>0 的可得代理）。
- 费率默认值如 §4；config `fund:` 段可调，回测不改代码。

## 7. 已知局限（v1 不做）

- **除息假跳修正（v1 已实现，方法保守）**：akshare 单位净值在分红除息日不调整，
  出现单日 -15%~-25% 假跳（实测 569/2226 只基金、1064 个跳点，如 001678
  2021-11-11 单日 -23.5%，实为约 0.35 元/份分红除息）。修正法：单日跌幅
  < -12% 视为除息，按分红再投资复权抹平缺口；当日真实损益近似为 0（保守）。
  不修正的后果是动量/回撤因子被系统性污染——除息基金永远垫底 → 组合只选
  不分红基金。精细修正须引入除息日公告数据（v2）。
- **权重预注册变更记录**：初版配置 mom3/mom6 为主权重，样本内全期回测
  年化 -3.2%（跑输基准夏普）。全期因子诊断显示动量类 IC 为负（A 股基金
  收益反转效应），低回撤因子 dd_pen 正 spread 显著（Top50-Bot50 月均
  +2.15%）。据此前瞻性（在看到修正后回测结果之前）将默认权重改为
  dd_pen 主导（0.55）——这仍是**同一样本上的第二次观察**，最终结论须以
  新样本外验证为准（OOS 登记已自动计数）。

- 基金经理评价、风格漂移检测、场内 ETF 折溢价套利。
- 持仓因子（重仓股重叠/风格暴露）未进信号——重仓数据天然滞后披露，v1 只用于
  推荐输出的**相关性提示**（TopN 基金间重仓股重叠 >30% 告警）。
- 规模数据为最新快照（雪球源无历史规模时间序列），初筛用最新值，存在轻微
  幸存者偏差——回测内另用"成立日期 + 净值可得起始日"做 PIT 修正。
- 巨额申购限制、暂停申购未建模。
- 净值为单位净值（未含分红再投），有分红的基金收益会被低估——动量信号分母
  一致，影响为截面同向偏差，长期高分红基金排名会偏低。

## 8. 验收与回测报告（2026-09-25 实测）

**验收状态**：pytest 210/210 全绿（原 197 + 新增 13）；`fund-backtest
--start 2021-01-01 --oos` 跑通出报告；已推送。

**回测结果（2021-01-04 ~ 2026-09-24，月频 Top10 等权，全部申赎费已扣）**：

| 指标 | 策略 | 沪深300 |
|---|---|---|
| 年化收益 | **+21.09%** | -2.95% |
| 夏普 | 0.78 | -0.08 |
| 最大回撤 | -49.34% | -45.60% |
| Calmar | 0.43 | -0.06 |
| 累计收益 | +187.7% | -15.7% |
| 交易成本合计 | 25.7 万元（期初 100 万） | — |

分年（策略 vs 基准）：2021 +12.93%/-6.21%；2022 -20.18%/-21.63%；
2023 -10.74%/-11.38%；2024 +15.98%/+14.68%；2025 +114.68%/+17.66%；
2026(至9月) +49.09%/-4.12%。

**如实报告（重要警示）**：

1. **2022 熊市回撤控制未达标**：策略 -20.18%，与基准相当，最大回撤 -49.3%
   甚至更深——低回撤因子在单边熊市失效（低回撤≠抗跌，选出的仍是高仓位
   股混基金）。"含 2022 熊市检验"的结论是**未通过**，不掩盖。
2. **收益高度集中于 2025-2026**：剔除 2025 年，策略年化约 +1%。收益主要
   来自近年市场风格（小盘/科技成长），样本外持续性存疑。
3. **多重观察**：同窗口共跑 3 次回测（初版权重 → 修正诊断 → 定版权重），
   OOS 台账已登记 3 次，DSR=0.85。第一次（动量权重）结果为负 → 说明
   该结果对权重敏感，p-hacking 风险真实存在。
4. **除息修正的模型风险**：修正把除息缺口全部记为分红（当日真实损益=0
   假设），对高分红基金收益有轻微高估。
