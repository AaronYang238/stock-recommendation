## 关键结论

### ✅ 样本外双双为正
- strategy 样本外 +38.28%，年化 24.7%，夏普 1.36
- swing 样本外 +15.23%，夏普 0.49，盈亏比 2.35

### ⚠️ 必须警惕的信号
1. **训练/样本外倒挂**（两条皆是）：训练段差、样本外好。更可能是窗口覆盖了风格切换（训练=震荡/熊市，样本外=反弹/牛市），而非策略 alpha。
2. **样本外 IC 为负**（strategy -0.0994）：选股因子样本外负贡献，收益主要来自市场 beta（持仓暴露），非因子 alpha。
3. **权重过度集中 lowvol**（90-100%）：训练段巧合，非稳健规律。
4. swing 样本外最大回撤 -24.8% 仍偏大。

### 诚实评估
验收**通过但含金量打折**。驱动因素是行情 beta 而非选股 alpha（证据：样本外 IC 为负、权重极端单一）。
**建议**：引擎可继续用（样本外没亏、方向对），但别神化其选股能力；更适合作为**风控/纪律参考**（低波 + 盈亏比框架）。真正检验 alpha 成色的时刻是进入震荡市之后。

## 消融实验结果（2026-08-19，5年窗口）

### 消融① · 反追高入场闸门（期望增量）
| 场景 | 期望/笔 | 交易笔数 |
|---|---|---|
| 有闸门 | -0.0057 | 1477 |
| 无闸门 | -0.0055 | 2030 |
| 增量 | -0.0002 | 少 553 笔 |

**结论：闸门几乎无效**（期望增量≈0），挡住 27% 交易但未提升质量。

### 消融② · 反卖飞离场纪律（按笔盈亏比）
| 离场策略 | 盈亏比 |
|---|---|
| 吊灯移动止损 | 1.564 |
| 涨停即清 | 0.95 |
| 固定 +8% | 0.885 |
| 增量 vs 涨停即清 | +0.614 |
| 增量 vs 固定止盈 | +0.679 |

**结论：移动止损显著有效**（盈亏比 +0.6），是系统真正的 alpha 来源。

### 综合启示
- 移动止损（让利润奔跑）是核心价值，直接针对用户"过早止盈卖飞"风险。
- 入场闸门无显著贡献，不宜作为追高风险的主要防线。
