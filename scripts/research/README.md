# 一次性研究脚本（未纳入测试，结论仅供参考）

这些脚本是历次探索留下的临时实验（资金流、复合因子、回踩止盈止损、数据核对等），
**不在 pytest 覆盖范围内**，其中多数直接读 SQLite 或自带简化回测，
口径（成交价、涨跌停、退市、ST、PIT 估值）可能与 `aselect` 核心不一致，
尤其早于 2026-09 的回测口径修复（仓位槽账本、次日开盘成交、分板块涨跌停、
退市折价、按日 ST、逐日估值）。

- 需要可信结论时，请用 `python -m aselect.cli ...` 的正式命令复现。
- 运行方式：在仓库根目录执行 `python scripts/research/<name>.py`
  （脚本按当前目录读取 `.env` 与 `src/`）。
